# Эмулятор SNMP v2c-устройства и движок сценарного изменения метрик

## Описание проекта

Разработка конфигурируемого программного эмулятора сетевого устройства с поддержкой протокола SNMP v2c и движка для динамического изменения метрик по заданным сценариям. Проект реализуется совместно с индустриальным партнером «Юзергейт» (Usergate).

## Стек технологий

- Язык программирования: [Go / Python / C++]
- Протоколы и форматы: SNMP v2c, ASN.1 (BER), UDP
- Инструменты: [Wireshark, Git, Docker]

*Финальный стек технологий и архитектура проекта будут определены после согласования технического задания с индустриальным партнером.*
